# Heart Disease Prediction Using Machine Learning and Explainable AI

## 📌 Project Overview

This research-oriented project investigates the prediction of heart disease using statistical analysis, machine learning, and Explainable Artificial Intelligence (XAI) techniques.

The project follows an end-to-end predictive analytics workflow, from data preprocessing and exploratory analysis to model development, evaluation, interpretation, and explainability.

A key objective of the project is not only to evaluate predictive performance but also to understand **why machine learning models make particular predictions** using explainability techniques such as **SHAP and LIME**.

---

## 🎯 Objectives

The main objectives of this project are to:

* Explore and preprocess heart disease-related data.
* Perform exploratory and statistical analysis.
* Identify important patterns and relationships within the data.
* Develop multiple machine learning classification models.
* Compare predictive performance using appropriate evaluation metrics.
* Assess model performance through validation and evaluation procedures.
* Apply Explainable AI techniques to interpret model predictions.
* Identify influential features contributing to model predictions.
* Translate analytical and modeling results into meaningful research insights.

---

## 🔬 Methodology

The project follows a structured predictive modeling workflow:

### 1. Data Preprocessing

* Data cleaning
* Handling data quality issues
* Preparation of variables for analysis
* Feature preparation
* Preparation of training and testing data

### 2. Exploratory Data Analysis

Exploratory analysis was conducted to understand:

* Distribution of variables
* Relationships between predictors
* Patterns associated with heart disease
* Potential influential features
* Data characteristics relevant to predictive modeling

Visualizations were used to communicate important patterns and relationships.

### 3. Statistical Analysis

Statistical analysis was incorporated to investigate relationships within the dataset and support interpretation of the predictive modeling results.

### 4. Machine Learning Models

Multiple classification algorithms were implemented and evaluated, including:

* Logistic Regression
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* Decision Tree

The models were evaluated comparatively using appropriate classification performance measures.

### 5. Model Evaluation

Model performance was assessed using metrics such as:

* Accuracy
* F1-score
* ROC-AUC
* Other relevant classification measures

Performance comparisons were used to identify the strengths and limitations of the developed models.

### 6. Explainable AI

To improve the interpretability of machine learning predictions, Explainable AI techniques were incorporated.

#### SHAP

SHAP (SHapley Additive exPlanations) was used to investigate feature contributions and understand the influence of individual variables on model predictions.

#### LIME

LIME (Local Interpretable Model-agnostic Explanations) was used to provide local explanations for individual predictions and investigate how different features contributed to specific model outcomes.

The use of SHAP and LIME helped move the analysis beyond predictive performance toward **interpretable and explainable machine learning**.

## 🔎 Explainability

The project incorporates two complementary XAI approaches:

**SHAP → Global and feature-level model interpretation**

**LIME → Local interpretation of individual predictions**

This allows the analysis to examine both overall feature importance and individual prediction behavior.
